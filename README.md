# Dino RL

Double DQN для Chrome T-Rex Runner: бег, прыжок и присед.

- **Состояние:** 12 признаков (класс препятствия, время до него, скорость, зазор, ширина, присед, прыжок).
- **Действия:** `run`, `jump`, `duck`.
- **Обучение:** несколько окон Chrome одновременно, общий replay buffer и target network.
- **Финальный забег:** `epsilon = 0`, только `best_dqn.pt`.

## Установка

Нужны Python 3.12, [uv](https://docs.astral.sh/uv/) и Chrome/Chromium.

```powershell
uv sync
uv run playwright install chrome
```

Если используется Chromium вместо системного Chrome, поставьте
`BROWSER_CHANNEL = None` в начале `dino.py` и выполните
`uv run playwright install chromium`.

## Запуск

```powershell
uv run dino.py          # финальный забег
uv run dino.py --train  # обучение
uv run dino.py --play   # принудительно финальный забег
```

## Финальный забег

- Открывается одно окно Chrome (`WINDOWS = 1`), окно видно.
- Загружается `best_dqn.pt`; случайность отключена.
- Делается `FINAL_ATTEMPTS = 5` попыток; результат каждой пишется в `results.csv`.
- Если какая-то попытка прошла дальше `best_distance`, обновляется `best_dqn.pt`.
- Ограничения на длину эпизода нет; остановка — падение или `Ctrl+C`.
- Скорость игры ограничена текущим этапом (`CURRICULUM`); по умолчанию финал
  идёт на этапе 1 (`MAX_SPEED = 6.5`), где модель показывает лучшую дистанцию.

Для финала на максимальной скорости этап можно поднять в `dino.py`:

```python
curriculum_stage = 2  # MAX_SPEED = 13.0
```

На этапе 2 появляются птицы: середина требует приседа, низ — прыжка,
высокая птица безопасна для бега.

## Обучение

```powershell
uv run dino.py --train
```

- `WINDOWS = 5` окон Chrome, обучение headless.
- Загружается `best_dqn.pt`, если он есть; иначе `dqn.pt`.
- `TRAIN_GREEDY = True`: эпизоды без исследования, веса обновляются.
- `TIME_LIMIT_MINUTES = 240`: общий лимит обучения.
- `EPISODES = 3000`: лимит эпизодов на все окна.
- `best_dqn.pt` обновляется при улучшении рекорда; `dqn.pt` — каждые
  `SAVE_EVERY` эпизодов и при выходе.

Если нужно исследование, поставьте `TRAIN_GREEDY = False`: включается
`epsilon` (0.05 после загрузки `best_dqn.pt`), эпизод ограничивается
`MAX_EPISODE_SECONDS`, а рекорд проверяется отдельными жадными забегами
каждые `RECORD_EVERY` эпизодов.

## Результаты

Текущий `best_dqn.pt`:

```text
distance: 175 092
score:     4 377
episode:   168 845 решений
learn:      65 581 шагов обучения
```

Финальные замеры на этапе 1 дают разброс: один забег прошёл **63 225**
(1 580 очков), серия из пяти попыток — 2–6 тыс. Лучший тренировочный
результат 175 092 не всегда воспроизводится в финале: раскладка кактусов
меняется, а модель обучалась с обновлением весов прямо во время эпизода.
Поэтому финал делает несколько попыток и сохраняет лучшую.

## Файлы

- `dino.py` — агент, обучение и финальный забег.
- `best_dqn.pt` — лучшие веса (загружаются в финале и при обучении).
- `dqn.pt` — последние веса обучения (в git не входит).
- `results.csv` — журнал эпизодов и финальных попыток.
- `pyproject.toml`, `uv.lock` — зависимости.
- `src/dino/` — заготовка пакета.

## Что можно улучшить

1. **Проверять лучшую модель жадным забегом** после каждого улучшения, а не
   сохранять веса по тренировочной дистанции. Так `best_dqn.pt` будет
   соответствовать реальной финальной политике.
2. **Не обновлять веса во время забега**: собирать опыт в буфер, а обучение
   делать между эпизодами или на замороженной копии политики.
3. **Больше финальных попыток** или отдельный `evaluation.py` с несколькими
   сидами/раскладками.
4. Для этапа 2 (MAX_SPEED = 13) отдельно дообучать модель на птицах и
   высоких скоростях; текущий рекорд 175k получен на этапе 1.

## Остановка

`Ctrl+C`. В режиме обучения последние веса сохраняются; `best_dqn.pt`
остаётся лучшим.
